# psatomas.com

Personal website, technical portfolio, and blog. Built with Next.js (App Router),
TypeScript, Tailwind CSS, and MDX. Deployed to Cloudflare via GitHub Actions.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS
- MDX
- GitHub Actions (CI)
- Cloudflare (hosting)
